## ⚡ About Me

I build **AI systems that operate autonomously** — from multi-agent orchestration to edge-deployed intelligence on industrial hardware. Everything I build is designed to run **local-first**, with privacy and sovereignty at the core.

**What drives me:**
- 🧠 **Multi-Agent AI** — Autonomous systems with 200+ coordinated skills
- 📡 **Edge Computing** — ML inference on Raspberry Pi and industrial sensors
- 🔒 **Local-First** — Models run on-device before touching the cloud
- 🏭 **Industrial AI** — Predictive maintenance and anomaly detection
- 🇲🇾 **Malaysian Context** — PDPA-compliant, locally-aware solutions
